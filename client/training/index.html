In PLATFORMS, answers are platforms in an arena. Players move to the platform they think is correct before the timer ends. The question type determines which arena is built, and all text is drawn on a projector, so length matters. The diagrams on this page are generated from the game's level code.

Arenas

Island variations

Choice questions using the islands layout rotate through these designed levels. A level is used when its number of boards matches the question's answer count.

Text length

Text over a limit still plays; it is drawn smaller and the loader prints a note. The counts and timings in the next table are enforced.

The standard deck plays in both free-for-all and teams. Control cases play only when teams exist, and only when there is at least one case per team (three teams need three cases) — otherwise none are scheduled. The Showdown is a separate final mode: true/false, no points, last player standing.

Writing packs

Packs are written in the Pack Studio: type questions as a document (# starts a question, answers on the lines below, click the box beside the correct one) and preview each question in the game engine. Nothing to install; drafts save in the browser; export produces one JSON file to send to the host.
